# WARDOGS | RU · отдельный доступ к сбору · версия 1.8.1

Роль **`859738052666327040`** получает доступ только к созданию, проверке и остановке сбора игроков. Для неё добавлена отдельная команда **`/seed-gather`**. Право «Управление сервером» для этой команды не требуется.

## Команды для роли сбора и основных администраторов

| Команда | Действие |
| --- | --- |
| `/seed-gather start` | Объявить сбор на выбранном сервере и опубликовать карточку. |
| `/seed-gather status` | Проверить сбор и обновить карточку. |
| `/seed-gather stop` | Остановить сбор и закрыть карточку. |

Во всех трёх командах выберите в параметре `server` **«Сервер 1»** или **«Сервер 2»**. Команда `start` поддерживает прежние дополнительные параметры: `target`, `role`, `channel`, `minutes`, `instructions`.

По умолчанию карточка публикуется в канале запуска команды. Параметр `channel` позволяет выбрать другой текстовый канал. Подтверждение запуска, статус и ответ на остановку видны только автору команды; карточка публикуется для участников выбранного канала.

В примерах `main` и `second` соответствуют вариантам «Сервер 1» и «Сервер 2» в Discord:

```text
/seed-gather start server:second
/seed-gather start server:second channel:#сбор target:20 minutes:60
/seed-gather status server:second
/seed-gather stop server:second
```

Цель по умолчанию — 20 игроков, срок — 120 минут, уведомляемая роль — «Сидер». Все правила обновления карточки, защиты от повторных уведомлений и работы с двумя серверами сохранены. Подробное описание сбора находится в [UPDATE-1.8.0-RU.md](UPDATE-1.8.0-RU.md).

## Разделение прав

| Участник | `/seed-gather start/status/stop` | `/seed-admin` |
| --- | --- | --- |
| Роль `859738052666327040` без основной админской роли | Разрешено. | Запрещено. |
| Основная админская роль и право «Управление сервером» | Разрешено. | Разрешено. |
| Обычный участник | Запрещено. | Запрещено. |

Основные админские роли: `805429609457254450`, `815605974412558376` либо ваша существующая настройка `DISCORD_ADMIN_ROLE_IDS`.

**Не добавляйте `859738052666327040` в `DISCORD_ADMIN_ROLE_IDS`.** Доступ этой роли к сбору уже указан отдельно в программе. Если участник имеет также основную админскую роль и право «Управление сервером», он сохраняет административный доступ по этим отдельным правам.

Прежние `/seed-admin gather`, `/seed-admin gather-status` и `/seed-admin gather-stop` сохранены для основных администраторов. Они работают с теми же карточками и сборами, что и `/seed-gather`, без создания второго независимого учёта.

Роль сбора не получает права на изменение времени или баллов, массовые начисления, просмотр административных списков, управление VIP и Reserved slots, запуск резервных копий или остальные действия `/seed-admin`. Попытка их выполнить отклоняется до обращения к соответствующему сервису. Проверка роли выполняется при каждом запросе; снятие роли прекращает доступ к сбору.

Команда `/seed-gather` может быть видна в списке команд обычным участникам, но бот отклоняет её выполнение без разрешённой роли. Для ограничения видимости используйте настройки именно `/seed-gather` в **«Настройки сервера → Интеграции → бот сидинга»**. Не открывайте `/seed-admin` для роли сбора.

Отдельная группа позволяет сохранять ограничение «Управление сервером» у `/seed-admin`. Права Discord задаются на уровне команды, поэтому доступ к сбору выделен отдельно: [официальная документация Discord](https://docs.discord.com/developers/interactions/application-commands#permissions).

Кнопкой «Как подключиться» в публичной карточке по прежнему могут пользоваться все участники.

## Обновление

1. Остановите бот сидинга. Сохраните постоянный `DATA_DIR`, включая `seeding.sqlite`, и действующие переменные окружения с ключами шифрования.
2. Замените файлы программы содержимым архива 1.8.1. Постоянные данные и секреты сохраните.
3. Запустите бота. Команды зарегистрируются автоматически; проверьте запись `discord_commands_registered` в журнале.
4. У роли `859738052666327040` должно быть обычное право **«Использовать команды приложений»** в канале запуска. Если доступ к командам бота ранее ограничивался в интеграциях, разрешите этой роли именно `/seed-gather`.
5. От участника с этой ролью проверьте `/seed-gather start`, `status` и `stop`. Для проверки отказа используйте участника без основных админских ролей.

**Новые переменные не нужны.** Список основных администраторов, привязки Steam, время, баллы, интеграция донатного VIP и работа слотов на обоих серверах сохраняются.

Проверки сборки: `npm run check` и `npm test`. Локально проверены 52 JavaScript-файла; все **106 тестов прошли**, включая разрешённые команды сбора и отказ в остальных админских действиях. Проверка на действующем Discord выполняется после установки с вашими настройками.
