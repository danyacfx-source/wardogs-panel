# Discord → WARDOGS RU: синхронизация розыгрышей

Это отдельный read-only бот для страницы `https://wardogs-ru.ru/giveaways/`. Он запускается планировщиком cron, читает последние сообщения только из канала розыгрышей и обновляет публичный файл `data/giveaways.json`. Страница загружает этот JSON со своего домена. Токен Discord никогда не передаётся браузеру.

Требования: PHP 8.1 или новее и включённое расширение cURL.

## 1. Создайте отдельного Discord-бота

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **New Application**.
2. В разделе **Bot** создайте бота, отключите **Public Bot** и включите **Message Content Intent**.
3. Нажмите **Reset Token**, скопируйте новый токен и сохраните его в менеджере паролей. Не присылайте токен в чат и не вставляйте его в файлы сайта.
4. В **OAuth2 → URL Generator** выберите scope `bot`; из разрешений оставьте только **View Channels** и **Read Message History**.
5. Добавьте бота на сервер `403186008579112973`. В настройках канала `1546639691607183390` разрешите ему видеть канал и читать историю. Для остальных каналов доступ лучше запретить.

## 2. Узнайте ID бота-автора розыгрышей

Синхронизатор принимает сообщения только от одного заданного автора. В Discord включите **Настройки пользователя → Расширенные → Режим разработчика**, щёлкните правой кнопкой по существующему боту **WARDOGS RU** и выберите **Копировать ID пользователя**. Это значение понадобится как `giveaway_author_id`.

Имя бота использовать для проверки нельзя: имя можно подделать, а цифровой ID — нет.

## 3. Разместите бота вне публичной папки

Загрузите папку `discord-giveaways-bot` в домашний каталог хостинга, но **не** в `public_html`, `www/wardogs-ru.ru` или другой корень сайта. Например:

Для стандартного Linux-хостинга REG.RU с ispmanager структура обычно выглядит так:

```text
/var/www/u1234567/data/discord-giveaways-bot/       ← бот и секретный config.php
/var/www/u1234567/data/www/wardogs-ru.ru/           ← публичные файлы сайта
```

Замените `u1234567` на логин своего хостинга. Если в панели показан другой базовый путь, используйте его без изменений.

Скопируйте `config.example.php` в `config.php`, затем заполните четыре значения:

```php
'bot_token' => 'ТОКЕН_НОВОГО_READ_ONLY_БОТА',
'giveaway_author_id' => 'ID_СУЩЕСТВУЮЩЕГО_БОТА_WARDOGS_RU',
'output_file' => '/var/www/u1234567/data/www/wardogs-ru.ru/data/giveaways.json',
```

`guild_id` и `channel_id` уже заполнены. Права доступа: каталог бота `700`, `config.php` — `600`, `sync.php` и файлы `src` — `644`. Каталог сайта `data` должен существовать и быть доступен на запись владельцу хостинга.

## 4. Проверьте подключение без изменения сайта

Через SSH выполните команду, подставив свой путь и доступную версию PHP:

```bash
php /var/www/u1234567/data/discord-giveaways-bot/sync.php --check
```

Режим `--check` обращается к Discord, проверяет канал, права и ID автора, но не изменяет `giveaways.json`. В успешном сообщении будут указаны количество прочитанных сообщений, сообщений нужного автора и найденных розыгрышей.

Если проверка прошла, выполните первую настоящую синхронизацию:

```bash
php /var/www/u1234567/data/discord-giveaways-bot/sync.php
```

Успешный результат выглядит так: `Synced 1 giveaway(s).` После этого откройте `https://wardogs-ru.ru/data/giveaways.json`, а затем `https://wardogs-ru.ru/giveaways/`. В JSON и коде страницы не должно быть токена.

## 5. Добавьте cron в панели REG.RU

В панели хостинга откройте **Планировщик заданий (cron)**, выберите выполнение PHP-скрипта и задайте запуск раз в 5 минут:

```cron
*/5 * * * * /opt/php/8.3/bin/php -f /var/www/u1234567/data/discord-giveaways-bot/sync.php >> /var/www/u1234567/data/discord-giveaways-sync.log 2>&1
```

Замените `u1234567` на свой логин, а `8.3` — на выбранную в панели доступную версию PHP 8.1 или новее. Если выбран тип **Выполнить PHP-скрипт**, укажите путь `discord-giveaways-bot/sync.php` относительно папки виртуального сервера, поле **Аргументы** оставьте пустым и выберите PHP 8.1+. Не настраивайте вызов скрипта по URL: он специально недоступен через веб.

## Безопасность и обслуживание

- Бот ничего не отправляет и не изменяет в Discord; ему не нужны `Send Messages`, `Manage Messages` или права администратора.
- Читаются максимум 100 последних сообщений; публикуются максимум 20 записей и только от точного `giveaway_author_id`.
- Если канал недоступен или среди последних сообщений нет сообщений нужного автора, публичная лента не очищается.
- Полученный текст очищается и ограничивается по длине. React выводит его как текст без HTML.
- JSON заменяется атомарно. При сетевой ошибке, неправильном ответе или rate limit последняя корректная версия сохраняется.
- `config.php` исключён из Git. Никогда не переносите его в архив сайта.
- Если токен попал в переписку, журнал или публичную папку, немедленно сделайте **Reset Token**, обновите `config.php` и завершите старые сессии.
- Раз в месяц проверяйте журнал cron; удаляйте или архивируйте его, чтобы он не рос бесконечно.
