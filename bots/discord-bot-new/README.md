# WARDOGS v2 — единый Discord-бот

Многофункциональный Discord-бот на `discord.py` для сервера WARDOGS.

## Возможности

- **Тикеты** — создание/закрытие тикетов с persistent-кнопками и транскриптами
- **Розыгрыши** — автосинк активных розыгрышей из v1, персистентная кнопка «🎉 Участвовать», автоподведение итогов
- **Автоподкачка данных сервера в БД** — участники+роли, каналы/категории, события (вход/выход, создание/удаление ролей/каналов)
- **Уровни и XP** — за сообщения, лидерборд, rank-карточка
- **Роли активности** — автовыдача ролей за голос/сообщения/уровень
- **Стримеры** — отслеживание Twitch и анонсы стримов
- **Зеркало** — копирование сообщений из одного канала в другие
- **Авто-модерация** — анти-спам, капс, ссылки, маты, предупреждения
- **Временные голосовые каналы**
- **Автоперевод** сообщений в заданных каналах
- **Логирование** событий сервера
- **Анонсы**

## Установка

```
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните значения.

## Запуск

```
python bot.py
```

При первом запуске из рядом лежащей БД v1 (`wardogs.db`) автоматически переносятся **активные розыгрыши** (со всеми участниками и id сообщений), чтобы идущий розыгрыш не отвалился при переезде.
