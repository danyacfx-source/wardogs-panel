# Аудит административной панели

Дата проверки: 26 сентября 2026.

## Реализовано

- Кланы: каталог, поиск, создание/редактирование, карточка с лидером и составом, переход в карточку игрока.
- VIP: сроки, бессрочная выдача, изменение, отзыв, поиск, фильтры, повторная синхронизация и журнал операций.
- Тикеты: список, фильтры, статусы, приоритеты, исполнитель, комментарии и история обработки.
- Discord: журнал ролевых действий, список голосовых комнат, Steam ↔ Discord, диагностика отсутствующих/пустых/не настроенных ролей.
- Игроки: Steam-аватар, часы, сессии, статистика серверов, клан, метки, сводная история наказаний и CSV-экспорт.
- Баны: срочные и постоянные баны, причина, поиск/сортировка, карточка Steam, серверный CSV-экспорт.
- Права: шаблоны, массовое применение шаблона к выбранным ролям, сравнение двух ролей, вычисленные права пользователей, поиск конфликтных комбинаций и аудит изменений.
- Интерфейс: мобильные брейкпоинты, focus trap, Escape, Ctrl+K, Ctrl+R, skeleton-загрузки и единые сообщения об ошибках.

## Настройка интеграций

- Временные комнаты, их владельцы и участники приходят из внутреннего API «Асуны Юки». Для управления задаются `DISCORD_BOT_PANEL_URL` и `DISCORD_BOT_PANEL_TOKEN`; токен никогда не попадает в браузер.
- Редактирование бана выполняется безопасной последовательностью снять → выдать заново. При ошибке панель пытается восстановить исходный бан. Массовое снятие ограничено 50 записями и возвращает результат для каждого SteamID.
- История состояния сервисов хранится в памяти процесса и фиксирует переходы «работает ↔ сбой». После рестарта начинается новый журнал.
- Steam-аватары требуют `STEAM_API_KEY`; без него интерфейс показывает буквенный fallback.
