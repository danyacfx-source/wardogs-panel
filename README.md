# RCON Panel RUBEZH

Веб-сайт мониторинга и административная панель для игровых серверов, работающих через HTTP RCON API WARDOGS/Dark RCON.

## Быстрый запуск

Требования: Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
Copy-Item .env.example .env
Copy-Item servers.example.json servers.json
# для локального запуска замените WARDOGS_ENV=production на development
python -m uvicorn app.main:app --host 127.0.0.1 --port 8236
```

После запуска:

- публичный сайт: `http://127.0.0.1:8236/`;
- административная панель: `http://127.0.0.1:8236/panel`;
- калькулятор: `http://127.0.0.1:8236/calc`;
- статистика: `http://127.0.0.1:8236/stats`;
- активность: `http://127.0.0.1:8236/activity`;
- проверка приложения: `http://127.0.0.1:8236/api/health`.

Перед публичным развёртыванием заполните `.env` и `servers.json`. Не включайте `WARDOGS_DEV_AUTH` на публичном сервере.
В production оставьте `WARDOGS_ENV=production`: приложение откажется стартовать без HTTPS,
PostgreSQL URL, реального `servers.json`, RCON-токенов и Discord-секретов.
SQLite оставлен только как лёгкий локальный fallback для разработки.

## Основные возможности

- публичный мониторинг серверов без показа списка игроков;
- отображение количества игроков, карты, режима, счёта и ID сервера;
- Steam-вход и привязка Discord;
- разграничение прав по Discord-ролям;
- управление игроками, банами, матчем, картой и освещением;
- редактирование ротации карт с перестановкой, добавлением и удалением записей;
- бан-лист с поиском, сортировкой, пагинацией, Steam-ссылками и быстрым копированием ID;
- удобные подтверждения опасных действий без системных `prompt`/`confirm`;
- редактор прав Discord-ролей с группами, шаблонами, копированием и массовым сохранением;
- каталог администрации с поиском по Steam, Discord и ролям;
- просмотр и изменение конфигурации сервера;
- резервные места и горячая выдача доступа по SteamID64;
- аудит действий, статистика и калькулятор;
- адаптивный интерфейс в стиле WARDOGS;
- полный артиллерийский калькулятор WARDOGS/RUBEZH: карты Bakurani, Ozeti и Zestafona, выбор вооружения, MIL/азимут, поправка огня, слои, маркеры, линейка, импорт/экспорт и сохранённые цели;
- локально встроенный frontend калькулятора с переводами, иконками, контурами и экспериментальными баллистическими payload-данными;
- same-origin allowlist-прокси для тяжёлых картографических тайлов: браузер не обращается к внешнему хосту напрямую, а endpoint принимает только известные карты, zoom 0–7 и бинарные tile-имена.
- карточки игроков: защищённый поиск по SteamID/нику, агрегированная статистика по серверам, накопленное игровое время, счётчик сессий, первое/последнее наблюдение и действия над игроком из live-контекста.
- расширенный рейтинг игроков: сортировка по убийствам, K/D, времени, сессиям и последней активности, поиск и прямые ссылки на Steam;
- приватные заметки администрации в карточках игроков с отдельным Discord-правом, аудитом добавления/удаления и хранением в SQLite/PostgreSQL.
- история банов, снятий банов, киков и slay в карточке игрока — показывается только сотрудникам с правами на баны или аудит.
- административные метки игроков с цветами и отдельным Discord-правом;
- локальный справочник кланов: создание, редактирование, удаление и назначение игроку прямо из карточки;
- VIP-слоты по серверам: бессрочная или срочная выдача, автоматическая синхронизация с резервом, повтор синхронизации и автоматическое снятие после окончания;
- внутренние тикеты администрации: приоритеты, статусы, привязка игрока, исполнитель, комментарии, поиск и фильтры;
- временные баны на 1 час, 1/3/7/30 дней с автоматическим разбаном; постоянные баны и внешние записи также поддерживаются;

### Калькулятор карт

Страница `/calc` использует локально vendored приложение в `static/calc-app/`. Высокодетальные тайлы не раздувают архив релиза: они выдаются через строго ограниченный `/calc-assets/...` прокси с кэшированием и фиксированным upstream `zavod-wardogs.ru`; произвольные URL и SSRF через этот endpoint невозможны. Если нужен полностью автономный офлайн-режим, позже можно заменить upstream на собственное объектное хранилище без изменения интерфейса калькулятора.

Полное техническое описание находится в [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md).

Для Docker, systemd, Nginx/Caddy и резервного копирования см. [deploy/README.md](deploy/README.md).

## Проверки

```powershell
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python -m compileall -q app tests
node --check static/app.js
node tools/build-vue-render.mjs --check
```

Тесты покрывают health-check, readiness, security-заголовки, CSRF-cookie, миграции,
tamper-evident аудит, idempotency, хэширование сессий, кэширование и запрет доступа гостей.
Vue-шаблоны заранее скомпилированы, поэтому production CSP работает без `unsafe-eval`.
После изменения `static/index.html` или `static/panel.html` пересоберите их командой
`node tools/build-vue-render.mjs`.

Для переноса существующей SQLite-базы в PostgreSQL используйте
`deploy/migrate-sqlite-to-postgres.py` после создания пустой базы PostgreSQL.

## Безопасность

Файлы `.env`, `servers.json`, `site.db`, WAL/SHM базы и виртуальное окружение не входят в финальный архив. В комплект включены только шаблоны `.env.example` и `servers.example.json` с пустыми секретами.
